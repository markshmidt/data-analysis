# Data Analysis SQL

This repository contains my hands-on practice in SQL analytics, database design, performance optimization, and business-driven data analysis.

The goal of this project is not only to write queries, but to:
- Think in terms of business questions
- Practice real-world dataset modeling
- Improve query performance using indexes
- Work with transactions and constraints

## Repo structure

### 📁 postgres-ecommerce-dataset/

Tool: PostgreSQL + DataGrip

This part simulates a real production database environment with E-commerce Oilst Brazillian dataset.
PostgreSQL was chosen because it reflects how SQL is used in real backend systems and production databases.

### 📁 duckdb-notebooks/

Tool: DuckDB + Python

This part focuses on analytical SQL inside Python notebooks with volunteers analytics datasets from my Data Analyst Assistant job.
DuckDB was chosen for lightweight, high-performance analytical querying without server setup.
