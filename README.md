# 📊 Data Analysis Projects

This repository contains a collection of **data analysis projects** demonstrating my ability to work with data across **multiple tools and technologies**, including **Excel / Google Sheets, SQL, Python, JavaScript, Tableu, and data visualization tools**.

The projects focus on **real analytical tasks** such as data cleaning, joining datasets, filtering records, extracting dates from logs, visualizations and answering business or operational questions.


---
## Structure

**Python** (`Python/`) — EDA and reporting notebooks using Pandas, NumPy, Matplotlib, and Seaborn.
Datasets include Titanic survival data, Natural Earth geographic data, and real volunteer program
operational records (hours logs, sign-up trends, coaching sessions).

**SQL** (`sqls/`) — Two sub-projects: operational reporting on volunteer data using **DuckDB**
(in-process SQL on files, reusable views, monthly aggregations); and e-commerce analytics on the
Olist Brazilian dataset (100K+ orders, 8 tables) using **PostgreSQL** and DataGrip —
CTEs, window functions, multi-table joins, organized as production-style `.sql` files.

**Data Engineering** (`Data_Lakehouses/`) — Medallion architecture on Databricks with Delta Lake
and PySpark; dimensional modeling (star schema, staging → mart) with PostgreSQL and SQLAlchemy.
Details in [`Data_Lakehouses/README.md`](Data_Lakehouses/README.md).

**Tools across this repo:** Python · Pandas · SQL · PostgreSQL · DuckDB · PySpark · Delta Lake ·
Databricks · Matplotlib · Seaborn · Plotly · Tableau · Excel / Power Query · DataGrip · Jupyter
